# TAKITA

Website giới thiệu và cung cấp thiết bị xây dựng của TAKITA (Tân Kiến Tạo).

## Công nghệ

- Next.js
- TypeScript
- Tailwind CSS

## Nội dung website

Website giới thiệu các sản phẩm và phụ tùng thiết bị xây dựng, bao gồm:

- Cẩu tháp
- Vận thăng
- Phụ tùng cẩu tháp
- Phụ tùng vận thăng
- Thiết bị và phụ kiện xây dựng

## Chạy project

```bash
npm install
npm run dev
